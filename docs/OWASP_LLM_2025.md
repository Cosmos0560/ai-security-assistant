How ai-security-assistant v1.1.0 addresses each item. "Core" is the item the project exists for;
"Applies" means the risk is real for this tool and has controls; "N/A" means the tool has no such
surface. Links point to the module that implements the control and the tests that hold it. The
measured numbers are in the [README](../README.md#evaluation) and
[THREAT_MODEL.md](THREAT_MODEL.md).

## Known gaps

- LLM01: attacker-chosen text inside a valid summary (`summary_manipulation`) is not detected;
  it is the measured residual risk (7/11 under `all`), mitigated only by the report label.
- LLM01, LLM09: a forced severity upgrade is accepted by design (D33).
- LLM02: secrets that only high entropy would reveal are not detected (entropy detection off).
- LLM09: a Windows misstatement with no code near it passes check 9; distributed and low-and-slow
  spraying are not seen; severity has a floor and no ceiling.
- Mock numbers measure pipeline mechanics. The real-model numbers are single runs and do not
  generalize.
